# WileyWorx site

Director, producer, and EP portfolio for Jack Wiley. Replaces the Network Solutions / Web.com site at wileyworx.com.

## Stack
Astro, static, Vercel.

## Local
```
npm install
npm run dev
```

## Domain
Keep wileyworx.com at Network Solutions until DNS is pointed at this Vercel project. After deploy, add the domain in Vercel and update nameservers or A/CNAME records.

## Scope
This repo is Jack Wiley / WileyWorx only. It is not Gasworks.
